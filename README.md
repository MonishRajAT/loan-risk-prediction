# 🏦 AI Loan Risk Prediction System

An end-to-end Machine Learning project that predicts loan approval risk using applicant financial data and provides explainable insights.

👉 https://your-app-name.streamlit.app

## 📌 Project Overview

This project builds a complete ML pipeline to predict whether a loan applicant is likely to be approved or rejected.

It includes:

- Data preprocessing
- Model training & comparison
- Risk scoring system
- Explainable AI (SHAP)
- Interactive web application using Streamlit
- Deployment on cloud

---

## ⚙️ Features

✔ Predict loan approval (Approved / Rejected)  
✔ Risk Score calculation (0–100%)  
✔ Risk classification (Low / Medium / High)  
✔ Explainable AI (feature contribution)  
✔ Clean and professional UI  
✔ Fully deployed web app  

---

## 🧠 Machine Learning Model

- **Algorithm Used:** Random Forest Classifier  
- **Comparison Model:** XGBoost  
- **Accuracy:** ~77–82%  

### Why Random Forest?
- Handles tabular data well  
- Reduces overfitting  
- Provides feature importance  

---

## 📊 Important Features

The most influential factors in prediction:

- Credit History ⭐ (most important)
- Applicant Income
- Loan Amount
- Property Area
- Employment Status

---

## 🔍 Explainable AI

This project uses **SHAP (SHapley Additive exPlanations)** to explain predictions.

It shows:

- Which features increased approval chances  
- Which features decreased approval chances
